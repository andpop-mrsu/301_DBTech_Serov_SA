# Структура файлов данных

## genres.txt 

Файл содержит наименования различных жанров.

Например:
- Adventure - приключения;
- Comedy - комедия;
- Fantasy - фантастика.

## movies.csv

Файл содержит информацию о фильмах.

Основные поля:
- movieId - идентификатор фильма;
- title - название фильма;
- genres - жанры фильма.

## occupation.txt

Файл содержит названия профессий.

Такие как:
- administrator - администратор;
- programmer - программист;
- lawyer - адвокат.

## ratings.csv

Файл содержит оценки пользователей.

Основные поля:
- userId — идентификатор пользователя;
- movieId — идентификатор фильма;
- rating — оценка фильма;
- timestamp — время выставления оценки.

## tags.csv

Файл содержит теги фильмов.

Основные поля:
- userId — идентификатор пользователя;
- movieId — идентификатор фильма;
- tag - название пользовательского тега;
- timestamp — время добавления тега.

## users.txt

Файл содержит информацию о пользователях.

Такую как: 
- Идентефикатор пользователя;
- Имя и фамилию;
- Почтовый адрес;
- Пол;
- Дату рождения;
- Профессию.


## rating.count.txt

Содержит две строки:
- Значение минимального идентификатора пользователя из файла ratings.csv и количество строк с этим идентификатором;
- Значение максимального идентификатора пользователя из файла ratings.csv и количество строк с этим идентификатором.

## sqlite.txt

Содержит:
- номер версии SQLite;
- режимы вывода данных, доступные в утилите sqlite3.
