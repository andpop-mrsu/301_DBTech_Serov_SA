# Лабораторная работа 2

## Требования

Для работы необходимы:

- Python 3
- SQLite 3
- Bash

## Структура

В каталоге находятся:

- `make_db_init.py` — программа генерации SQL-скрипта;
- `db_init.sql` — SQL-скрипт создания таблиц и добавления данных;
- `db_init.bat` — скрипт запуска;
- `movies.csv` — данные о фильмах;
- `ratings.csv` — оценки пользователей;
- `tags.csv` — теги фильмов;
- `users.txt` — данные пользователей;
- `genres.txt` — справочник жанров;
- `occupation.txt` — справочник профессий.

## Запуск

Необходимо перейти в каталог `Task02` и выполнить:

    ./db_init.bat

После выполнения будет создана заполненная база данных:

    movies_rating.db

Программа `make_db_init.py` автоматически формирует файл `db_init.sql`, после чего SQLite выполняет этот SQL-скрипт.

При повторном запуске таблицы удаляются и создаются заново.
